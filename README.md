# LangGraph Project

A Python project using LangGraph for building agentic applications.

## Setup

1. Create virtual environment:
```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. Install langgraph:
```bash
python -m pip install langgraph
```

## Running Tests

```bash
python test.py
```

## Project Structure

- `test.py` - Basic LangGraph functionality tests
